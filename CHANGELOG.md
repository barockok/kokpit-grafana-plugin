# Changelog

### Features

- 3-step SLO configuration wizard (Basics, SLI Queries, Review)
- Live Grafana dashboard panel preview
- YAML config export for Kokpit CLI
- Support for ratio and custom SLI types
- Composite SLO calculation (weighted, minimum, average)
- Error budget burn rate alert configuration
- Template variable substitution in PromQL queries
